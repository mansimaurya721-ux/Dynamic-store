# 🛍️ Dynamic Store

A responsive and interactive e-commerce web application built using **HTML, CSS, and modern JavaScript (ES6+)**.

The application fetches live product and category data from a public REST API and provides dynamic search, category filtering, sorting, cart management, loading states, and error handling without requiring a page reload.

---

## 🚀 Features

- 🔄 Fetch live product data using REST API
- ⚡ Asynchronous API calls using `async/await`
- 🔎 Real-time product search
- 🏷️ Dynamic category filtering
- ↕️ Sort products by:
  - Price: Low to High
  - Price: High to Low
  - Name: A-Z
- 🛒 Add products to cart
- 💾 Persist cart data using `localStorage`
- ⏳ Loading skeleton while API data is being fetched
- ⚠️ User-friendly error handling
- 🔄 Dynamic DOM updates without page reload
- 📱 Responsive design for desktop, tablet, and mobile
- 🧩 Modular JavaScript using separate API and application logic files
